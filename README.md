# Homebrew Bootwitch

This is the Homebrew tap for [Bootwitch](https://github.com/naomijnguyen/Bootwitch-CLI), a portable project scaffolder for macOS and Linux.

## Install

```sh
brew install naomijnguyen/bootwitch/bootwitch
```

Then open the command guide:

```sh
bootwitch help
```

The formula installs the tagged Bootwitch release from the public source repository and verifies its SHA-256 checksum before installation.
